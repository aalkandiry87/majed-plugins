# الهوية البصرية: علي الكندري (v1)

**الدليل الكامل:** [هوية علي الكندري](https://claude.ai/artifact/ANvHYAWV5g1PMNXAkrJqBD) · المصدر: `book/index.html`
**الحالة:** تنتظر اعتماد المالك (البند n011 على اللوحة).

## الملخص
- **الفكرة:** كادر كاميرا (4 زوايا) وفي نصه حرف «ع» بخط الرقعة. الكادر يمثل التصوير والـ AI، والحرف يمثل اللمسة الإنسانية العربية.
- **الألوان:**

| الاسم | اللون | الاستخدام |
|---|---|---|
| إسبريسو | `#1B1411` | النص والخلفيات الداكنة |
| رمل | `#F4EBDD` | الخلفية والنص على الداكن |
| لاتيه | `#C9A27E` | خطوط وتفاصيل |
| **غروب** | `#E3622D` | اللون المميز. لون واحد بس في كل تصميم |
| خليج | `#17657A` | لمسة الشغل والـ AI |

- **الخطوط:**
  - Tajawal Bold للعناوين.
  - Readex Pro للنص.
  - Inter بأحرف كبيرة للإنجليزي.
  - Aref Ruqaa للعلامة بس.
- **السلاسل:** كل سلسلة لها لون:
  - شغلي: إسبريسو.
  - قهوة وفكرة: رمل.
  - الخير ياي: غروب.
- **الغلاف:** الكادر ← اسم السلسلة ← عنوان بسطرين (الثاني بلون مميز) ← رقم الحلقة. كل الكلام داخل نص الصورة، عشان يبين كامل لما الشبكة تقص الغلاف 3:4.

## الملفات
- `tokens.json`: كل القيم (ألوان، وخطوط، وأحجام، ومنطقة آمنة).
- `assets/`:
  - الشعار بنسختين (logo-light وlogo-dark).
  - الشعار مع الاسم (wordmark).
  - لوحة الألوان (palette).
  - 3 أغلفة سلاسل.
  - 5 أغلفة هايلايت.
  - محاكاة شبكة الحساب (grid).
- `src/kit.html` + `src/export.js`: مصدر كل الصور. تعدّل ثم تشغّل `node src/export.js`.
- أداة الريلز (`team/tools/reel/`) تختم كل ريل بغلاف «الخير ياي» بهالهوية.

## تحتاج المالك (تغيير إعدادات حساب)
