# قوائم «خلص» لكل مرحلة

ما تنتقل أي مهمة للمرحلة اللي بعدها إلا إذا كل بنود مرحلتها متحققة. القسم يكتب في حدث اللوحة إنه راجع القائمة.

مراحل المهمة على اللوحة: **قائمة الانتظار** ← **قيد الشغل** ← **مراجعة** ← **خلص**

---

## 1. استلام المهمة (قائمة الانتظار ← قيد الشغل)
- [ ] المهمة لها صاحب واحد وموعد.
- [ ] الهدف مكتوب بجملة وحدة: وش يعتبر نجاح؟
- [ ] المدخلات موجودة (بريف، أو سكربت، أو ملفات). إذا ناقصة، المهمة تبقى «متوقف» وينضاف need.
- [ ] نعرف إذا المهمة فيها نشر أو إرسال أو صرف، وإذا فيها، ننتبه لها من البداية.

## 2. التنفيذ (قيد الشغل)
- [ ] الشغل محفوظ في `work/<القسم>/` وليس في المحادثة بس.
- [ ] أي رقم مكتوب له مصدر.
- [ ] ما صار أي نشر أو إرسال أو صرف أو تغيير إعدادات.
- [ ] نسجل حدث على اللوحة عند البداية وعند أي توقف.

## 3. المراجعة (قيد الشغل ← مراجعة)
- [ ] قائمة «خلص» الخاصة بالقسم (في `jd/`) كلها متحققة.
- [ ] الإملاء واللهجة مراجعة، وما فيها عبارات تبيّن إن الكلام مكتوب بالـ AI.
- [ ] التسليم يناسب المنصة (مقاس، مدة، منطقة آمنة).
- [ ] المدير التنفيذي راجع، أو وكيل quality-manager إذا كان الشغل إنتاج.

## 4. موافقة المالك (مراجعة ← ينتظرك)
تنطبق بس إذا الخطوة الجاية فيها نشر أو إرسال أو صرف أو دفع أو إعدادات.
- [ ] انضاف need على اللوحة، وفيه: وش بالضبط، والتكلفة إن وُجدت، والخيار المقترح، ورابط الملف.
- [ ] need واحد لكل عملية. ما نجمع 3 بوستات في موافقة وحدة.
- [ ] ننتظر حالة **approved** على هذا need بالذات قبل التنفيذ.

## 5. التنفيذ بعد الموافقة
- [ ] نفذنا اللي انوافق عليه بالضبط، بدون أي إضافة.
- [ ] سجلنا حدث على اللوحة فيه رقم need، ورابط النتيجة.
- [ ] إذا صار خطأ، نوقف ونرفع للمالك، وما نعيد المحاولة على شي يصرف.

## 6. خلص (مراجعة ← خلص)
- [ ] التسليم موجود ورابطه في المهمة.
- [ ] التقرير مكتوب بالصيغة: تم / الملفات / يحتاج المالك / متوقف / التالي.
- [ ] نقاط XP انحسبت حسب [levels.md](levels.md).
- [ ] المهمة اللي بعدها (إن وُجدت) انضافت للوحة لصاحبها.

---

## قائمة جودة الفيديو (قبل أي ريل)
- [ ] الهوك يبين في أول ثانيتين.
- [ ] 9:16، وجودة 1080 × 1920 أو أعلى.
- [ ] الكابشن مقروء، ويطابق الكلام، وداخل المنطقة الآمنة.
- [ ] الصوت مضبوط، وما فيه تقطيع أو صدى.
- [ ] المنتج والشعار مطابقين للأصل.
- [ ] الغلاف واضح ويبين في الجريد.
- [ ] الدعوة للتواصل وحدة وواضحة.
