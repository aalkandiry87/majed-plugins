# أداة ريلز «الخير ياي»

تسوي ريل موشن تايبوقرافي 9:16 من ملف نص. ما تحتاج تصوير، وما فيها توليد مدفوع، والموسيقى أصلية مؤلفة بالكود.

```bash
node render.js specs/<الاسم>.json /tmp/<الاسم>.mp4 --preview   # 3 صور معاينة
node render.js specs/<الاسم>.json ../../work/production/reels/<الاسم>.mp4
```

- `specs/*.json`: المشاهد (أسطر وأحجام ومدة)، والألوان، والمؤثر (`leaves` أو `rain` أو `stars`)، والمزاج الموسيقي (`dawn` أو `rain` أو `night`).
- الخطوط: Tajawal وReadex Pro، رخصة OFL (منسوخة من مستودع video-ad-editor).
- النص يبقى داخل المنطقة الآمنة لإنستقرام (من 330px فوق، إلى 520px من تحت، و150px من اليمين).
- **التسليم ملف بس.** النشر والجدولة بموافقة المالك على كل ريل لحاله.
