# دليل الشركة (team/README.md)

المالك: [علي الكندري]. المدير التنفيذي: جلسة Claude Code وحدة، وهي الوحيدة اللي تكلّم المالك.

## الفريق
- الباحث ([researcher.md](researcher.md)): يدوّر على الترندات والأفكار كل صباح.
- الكاتب ([writer.md](writer.md)): يكتب السكربت قبل التصوير بليلة.
- المونتير ([editor.md](editor.md)): يمنتج الفيديو بنسختين.
- الناشر ([publisher.md](publisher.md)): يجدول النشر بعد موافقة المالك.

## القواعد
1. كل تقرير يروح للمدير، مو للمالك.
2. حدّث اللوحة: لما تبدأ، لما تحتاج المالك، لما توقف، لما تخلص (شوف «بروتوكول اللوحة» تحت).
3. النشر والإرسال والصرف والدفع وتغيير الإعدادات: بموافقة المالك بس، لكل مرة لحالها.
4. «خلص» يعني قائمة التسليم كاملة (checklists.md).
5. ابقَ في مسارك: أي شغل برا وصفك يرجع للمدير.
6. أي تصحيح من المالك يصير قاعدة مكتوبة هنا.

## صيغة التقرير
كل تقرير للمدير، وكل تقرير من المدير للمالك، يكون بهالصيغة:

```
تم: وش خلّصت
الملفات / الروابط: المسار أو الرابط بالضبط
يحتاج المالك: القرار المطلوب، أو «لا شيء»
متوقف: وش موقفك، أو «لا شيء»
التالي: خطوتك الجاية، أو «فاضي»
```

## بروتوكول اللوحة
اللوحة: https://claude.ai/artifact/Y3jDsZrhxSZfQNSV13MKWU
قاعدة بياناتها (slug: `fb6cce62-4ccf-4e1e-a789-80c9d9fea0f5`) فيها أربع مجموعات: `agents/<الدور>` و`needs` و`recent` و`events`. أسماء الأدوار: researcher، writer، editor، publisher.

- تبدأ مهمة: حالتك «يشتغل» + اسم المهمة + جملة قصيرة.
- تحتاج المالك: حالتك «ينتظرك» + بطاقة في needs.
- تنتظر قسم ثاني: حالتك «ينتظر قسم» + اسم القسم.
- توقفت: حالتك «متوقف» + حدث stuck.
- خلصت: أضف التسليم في recent + حدث report للمدير + حالتك «فاضي».
- اقرأ الملف قبل ما تكتب، واكتب برقم إصداره (if_version) عشان ما تمسح شغل غيرك.
- الأوقات دايماً بنظام 12 ساعة (مثلاً 9:30 م).
- لو فشلت الكتابة في اللوحة، كمّل الشغل واذكرها في تقريرك.

### شكل البيانات
- `agents/<الدور>`: `{name, status, task, note, waiting_on, time}`
- `needs/<id>`: `{from, title, decision, link, time, ts, open}`. لما يقرر المالك تصير `open: false`.
- `recent/<id>`: `{from, title, link, link_label, time, ts}`
- `events/<id>`: `{type: "report" | "stuck", from, to: "المدير", text, time, ts}`

`ts` رقم بالثواني (Unix) للترتيب بس. اللي ينعرض هو `time`.
